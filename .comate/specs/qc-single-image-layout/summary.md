# 总结：质检平台改成和作业平台一致的三栏布局

## 需求

把三合一里的质检平台全面改成和作业平台一样的布局：左侧属性、中间单图、右侧数据列表，替换掉原来的 4 图网格 + 大图弹窗。

## 改动

### qc.html
- 顶栏：项目/质检员下拉、数量统计、每日质检量、通过/打回/保存按钮、设置、跳转链接。
- 三栏：左 `#qcCats`（属性）、中 `#qcViewer`（单图）、右 `#qcList`（列表 + 未质检/已通过/已打回/最近提交 页签）。
- 保留质检员登录弹窗、设置弹窗、toast。

### qc.js（整体重写，参照 anno.js）
- 项目/质检员选择、登录门槛、每日质检量（复用原逻辑）。
- 左侧属性按钮、中间单图查看器（pending/rejected 可编辑）、右侧列表。
- 通过/打回（保存框如有改动 + 提交结论 + 自动切下一张）、已打回页保存框（重置回 pending）、最近提交打回。
- 快捷键：属性键 + C 通过 + R 打回 + shift+3 隐藏；设置弹窗可自定义。
- 事件绑定。

### qc.css
- 改成三栏样式（qc-side/qc-main/qc-list-panel/qc-cats/qc-list-items/qc-item），去掉网格与 lightbox 相关样式。

## 校验与打包

- `qc.js` 通过 `node --check`。
- PyInstaller 重新打包 `dist/label-auto-dashboard.exe`（带图标），dist 仅此一个文件；已清理 `build/`。

## 结果

质检平台外观与作业平台一致：左属性、中间单图、右侧列表；通过/打回/保存框流程跑通。
