# 质检平台改成和作业平台一致的三栏布局

## 需求

把三合一里的质检平台（`/qc`）**全面改成和作业平台一样的布局**：左侧属性、中间一张图、右侧数据列表。替换掉现在「4 张网格 + 大图弹窗」的交互。

## 现状

质检平台现在是：右侧 4 图网格（`qc-grid-4`），每格一个「通过/打回」开关，点格子开全屏大图（lightbox）编辑框。

## 目标布局（对齐作业平台）

- 顶栏：项目 / 质检员 下拉、数量统计、每日质检量、`通过` `打回` 按钮、设置、跳转链接。
- 左侧：属性按钮（`#qcCats`）。
- 中间：单图查看器（`#qcViewer`，可画框/改框）。
- 右侧：图片列表（`#qcList`）+ 页签（未质检 / 已通过 / 已打回 / 最近提交）。

## 交互

- 右侧列表点某条 → 中间加载该图。
- **未质检（pending）**：中间可编辑，顶栏「通过/打回」→ 保存框（如有改动）→ 提交质检结论 → 自动切下一张。
- **已打回（rejected）**：中间可编辑，「保存」→ 保存框（平台会重置回 pending）。
- **已通过 / 最近提交**：只读浏览。

## 改动文件

1. `static/qc.html`：改成三栏布局（保留质检员登录弹窗、设置弹窗）。
2. `static/qc.js`：整体重写为单图流程（参照 anno.js，保留质检员选择/登录门槛/每日质检量/最近提交打回）。
3. `static/qc.css`：改三栏样式（`qc-side`/`qc-main`/`qc-list-panel`/`qc-cats`/`qc-list-items`），去掉网格与 lightbox 相关样式。

## 快捷键

- 数字/字母键：选属性（复用 anno 的属性快捷键体系，按项目隔离）。
- `C`：通过（未质检页）；`R`：打回；`Shift+3`：隐藏属性。
- 设置弹窗可自定义属性键 + 通过/打回/隐藏键。

## 边界与异常

- 未选质检员/项目：右侧显示空态，中间显示「请选择图片」。
- 无内置登录质检员（局域网访问）仍弹登录框；有登录的质检员显示每日质检量。
- 通过/打回失败：提示并停留在当前图，可重试。

## 预期结果

质检平台外观与作业平台一致：左属性、中间单图、右侧列表；通过/打回/保存框流程跑通。
