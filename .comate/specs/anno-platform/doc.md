# 作业平台（标注端）

## 背景与目标

现有平台已有「质检平台」（qc.html）和「数据看板」（index.html）。本次新增第三个平台「**作业平台**」，给**作业员/标注员**用，用来对分配给他的图片做框标注（画框），并在被打回后重新标注再提交。

## 整体布局（三栏 + 顶栏）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏： [项目▾] [作业员▾]          （右侧）[设置]               │
├───────────────┬──────────────────────────────┬────────────────┤
│ 左侧：属性按钮 │ 中间：照片（画框/编辑）       │ 右侧：图片列表   │
│ 前挡玻璃遮挡   │                              │ [未作业|已提交被打回]│
│ 车辆遮挡       │        (单张大图)            │ 图1            │
│ 车信标牌       │                              │ 图2            │
│ …             │                              │ …              │
└───────────────┴──────────────────────────────┴────────────────┘
```

- **左侧**：当前项目的所有属性（分类）按钮，点击选中，之后画的框都带该属性。
- **中间**：单张照片，支持与质检平台一致的操作（画框、移动、四角/四边缩放、双击删除、Delete 删除、C 提交）。
- **右侧**：图片列表，可切换「未作业」/「已提交被打回」两个页签；点击某条 → 中间加载该图。
- **顶栏**：左侧项目下拉 + 作业员下拉；右侧「设置」按钮，配置属性快捷键。

## 技术方案

纯前端新增 + 少量后端接口。

### 后端（dashboard.py）

新增两个接口，其余复用现有：

1. `GET /api/anno/setup`：返回项目列表，每项含 `{id, name, categories, annotators:[{uid,name,has_login}]}`。
   - annotators 来自 `/api/projects` 的 `assignees`（作业员 uid 列表），名字用 monitoring 的 `assignees` 里 uid→name 映射补全；`has_login = uid in _QC_LOGIN`。
2. `GET /api/anno/assigned?pid=&uid=&status=unannotated|rejected&offset=&limit=`：
   - 取该作业员分配文件 `proj["assignments"][uid]`，结合 `/images` 的 `annotated` / `qc_status` 过滤：
     - `unannotated`（未作业）：`annotated` 为假。
     - `rejected`（已提交被打回）：`qc_status == "rejected"`。

复用现有接口：`/api/projects/{pid}/annotation`（取框）、`/api/projects/{pid}/image`（取图）、`/api/qc/save`（保存框，会重置为 pending，即「提交」）。

登录门槛复用质检平台的逻辑：局域网 + 未内置账号 → 弹登录；127.0.0.1 本机不限。可复用 `/api/qc/reviewer_login`（或新增 `/api/anno/reviewer_login`，内部同一套）。

### 前端

- 抽离公共照片查看器：把 `qc.js` 里的 `colorFor` + `createViewer`（画框/移动/缩放/删除全逻辑）抽到新的 `static/viewer.js`，`qc.html` 与 `anno.html` 都引入它，避免重复。
- `static/anno.html` / `anno.css` / `anno.js`：三栏布局 + 列表 + 属性按钮 + 设置面板 + 快捷键。
- 照片操作与质检完全一致，直接复用 `createViewer`（editable=true）。

### 属性快捷键

- 每个属性（分类）可配置一个**单键快捷键**；按该键即选中该属性（用于后续画框）。
- 提交键默认 `C`，可改。
- **按项目隔离**：每个项目的属性不同，快捷键按 `项目id` 单独存 localStorage；切项目时自动载入该项目的快捷键（首次无则用默认）。
- **与质检平台隔离**：使用独立 localStorage key（如 `anno_shortcuts`），不与 `qc_shortcuts` 共用。

## 关键交互

1. 打开 → `init()` 自动登录（owner）+ `/api/anno/setup` 渲染项目/作业员。
2. 选项目 → 载入该项目快捷键、渲染左侧属性按钮、刷新右侧列表。
3. 选作业员 → 若局域网且未内置账号，弹登录（复用质检的登录框逻辑）；否则加载列表。
4. 点列表某条 → 中间 `createViewer` 加载该图；左侧属性选中后画框；双击/Delete 删除；拖角/边缩放。
5. `C`（或可配置的提交键）→ `POST /api/qc/save` 保存并回到未质检 → 从「未作业」列表移除该图 → 刷新列表。
6. 「已提交被打回」页签：点开可重新画框，`C` 提交后回到未质检（从该列表消失）。

## 边界条件与异常

- 项目无作业员 → 列表区显示「该项目暂无作业员」。
- 未选作业员/项目 → 不加载列表。
- 快捷键未配置的属性 → 只能点击左侧按钮选择，不响应按键。
- 提交后该图回到「未质检」，作业员列表里从「未作业」移除（后端 save 会重置 pending + 本地过滤）。
- 局域网未登录作业员 → 弹登录框，登录前不显示列表数据；127.0.0.1 不限。
- 快捷键与质检平台完全隔离，互不影响。

## 预期结果

- 新增独立的「作业平台」页面，作业员可按三栏布局查看列表、点选图片、左侧选属性、中间画框，`C` 提交。
- 属性快捷键按项目记忆、可配置，与质检平台隔离。
- 照片编辑操作与质检平台体验一致。
