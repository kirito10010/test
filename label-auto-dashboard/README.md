# Label Auto 外接看板

Label Auto 标注平台的本地看板工具，双击即可使用，无需安装任何依赖。

## 两个包分别给谁用

打包会同时产出两个 exe（**必须一起打，不要只打一个**）：

| 文件 | 给谁用 | 行为 |
|---|---|---|
| `LabelAuto-Admin.exe` | **超级管理员** | 三合一（数据看板 + 质检 + 作业），内置账号，可切换质检员 / 作业员 / 平台 |
| `LabelAuto-Staff.exe` | **员工**（质检员 + 作业员） | 用自己账号登录，只进有权限的那个平台，不能切换；质检员改属性时走内置管理员权限 |

## 启动方式

运行 `python dashboard.py`，浏览器会自动打开 `http://127.0.0.1:5221`。

> 双击 exe 时若已有同名实例在跑，会直接打开已运行实例的页面（不会重复起服务）。

## 功能

| 功能 | 说明 |
|------|------|
| 标签巡检 | 选项目 + 选标签（可多选，如「前挡玻璃遮挡」），列出命中图、框坐标、质检状态、归属质检员，可按状态/质检员筛选，一键导出 CSV。不选标签时即为整批图，状态选「未作业」可筛出作业员还没做的图 |
| 误通过核查 | 填「禁止出现的标签」集合，查出「已质检通过(passed)但仍带这些标签」的图（不该放行却被通过的） |
| 质检看板 | 各项目进度、质检员通过/打回统计、标注员合格率 |
| 标签分布 | 每项目各分类框的数量条形图 |
| 导出 | 一键下载 全量/仅质检通过/YOLO 格式的标注 |
| 图片预览 | 点击结果中的图可放大查看并叠加标注框 |

## 技术说明

- 本地服务用 Python 标准库实现，零第三方依赖（Python 3 即可）。
- 服务会代理 Label Auto API（`http://172.21.205.141:8771`），解决跨域（CORS）问题。
- 导出数据有 60 秒内存缓存，反复查询不会重复拉大文件。
- 平台数据是实时的，看板每次查询都是最新快照。

## 修改平台地址

若平台地址变化，编辑 `dashboard.py` 顶部的 `BASE` 变量即可。
